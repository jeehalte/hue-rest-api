# Agents

Custom agents and workflows for the Hue REST API project.

## Available Agents

### Code Review
- Analyzes code for bugs, security issues, and best practices
- Use for PR reviews and refactoring validation

### Explore
- Investigates codebase and answers research questions
- Use for understanding existing code and finding patterns

### Task
- Executes commands (tests, builds, lints)
- Use for long-running processes without blocking

### General Purpose
- Complex multi-step tasks with full toolset
- Use for intricate refactoring and feature implementation
